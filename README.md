# Meal Prep Planner

Frontend-only React implementation for the meal prep planner specs and userflow diagrams.

## Scripts

- `npm run dev` starts the Vite dev server.
- `npm run build` type-checks and builds the frontend.
- `npm run test` runs the Vitest test suite.
- `npm run lint` runs ESLint.

No backend is generated(yet). The app uses typed mock frontend state so the documented flows can be exercised locally.
