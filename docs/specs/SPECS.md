## Meal prep planner specifications

### Problem Statement

Meal prepping is a task that occupies one's time and effort as much as any job. Context switching between what groceries are available, what one wants to eat, what diet are they following and how much time do they have, how many people do they need to cook etc and this repeats for every meal of the day. 

Once a plan is in place, cooking becomes trivial. But setting up a plan is what takes up a lot of time and time is money. A meal prep planner that uses the current AI capabilities helps to organize your grocery lists, diet preferences, time, lifestyle etc and generates customized meal plans accordingly. 

### Features

Functional:

- Who is it for?
    - People who want to cook at home.

- What features and capabilities should the app allow?

    User
    - Create User Profile
    - Add Grocery lists

    Agent
    - Create Meal plans
    - Edit Meal plans
    - Compile grocery lists
    - Integrate with user's data on phone, social media.

- What information is needed by AI?
    - Grocery lists
    - Diet preferences
    - Personal information
    - Cuisines
    - Lifestyle factors
- What information is needed by AI, but not accessible yet?
    - What's in the fridge?
    - What's in your cupboards?
    - Grocery store details
- How should UI look like?
    - Per user: Meal plans, Profile, Data sources

- What is the lifecycle of a user?

    New User:
    1. Create a profile with following details:
        - Personal information like Name, Age, Gender
        - Diet Preferences: Allergies, vegetarian, omnivorous, high protein
        - Cusines: Asian, Indian etc
        - Lifestyle: Active, Inactive, Job
    2. Once profile is filed and saved, takes user to their home page.
    3. Home page has a Profile, Meal plans section but user sees the Agent pop up first, greeting the user and providing some quick actions to take.
    4. User can view meal plans, add Grocery sources or point the agent to their files and get those.

    Existing User:
    1. Login
    2. Sees the same as New User from Step 3 onwards.

- Web app or mobile?
    - start off as a web app for now.


### Architecture

#### Components

***Login Page***

New User login. Keep it simple for now and have only:

- Name
- Password

***Home Page***

User has different home page views:

- New User
    - Has a welcome message
    - Doesn't display anything yet, but add quick actions to take like Create Grocery list, Create Meal plan etc.

- Existing User
    - Has a welcome message
    - Links to today's meal plans generated by agent. 
    - Shows Number of meal plans created so far and any other stats needed: i.e Groceries running out

***Agent***

Agent is user's personal assistant that helps with creating meal plans for the user. They can greet the user and answer questions about:
    - What groceries are left?
    - What did they eat yesterday?
    - Ask for meal plans based on cuisine i.e I want to eat XYZ
    - Change profile details i.e I am on a diet ABC

Internally the following functions are supported:
    - Create Meal plan
    - Edit Meal plan
    - Delete Meal plan(Ask user before doing it)
    - Cancel Meal plan
    - View meal plan
    - Create grocery list
    - Edit grocery list
    - Delete grocery list(Ask user before doing it)
    - Edit user profile
    - View grocery list
    - Edit grocery list


*** User Profile Questionnaire ***

For new users only after Login:

- Ask user for following details:
    - Name
    - Age
    - Gender
    - Lifestyle: Active, Sedentary, Semi active
    - Diet preferences:
        - Allergies
        - Preferred Cuisine(s)
        - Preferred Protein(s)

***Meal plans***

Shows current day plan by default, with a calendar widget which shows dots indicating a meal plan was created for the day.
There are 3 toggles: Day, Week, Month.

    - Click Create
    - Fill details 
        - Name of recipe
        - Cuisine
        - Servings
        - Ingredients
        - Recipe step by step
        - Photos(if needed)
- Edit meal plan
    - Click Edit
    - Edit following:
        - Fill details 
        - Name of recipe
        - Cuisine
        - Servings
        - Ingredients
        - Recipe step by step
        - Photos(if needed)
- Delete meal plan
    - Go to meal plan
    - Click delete
- Cancel meal plan(In middle of editing or creating)
    - Click cancel
- View meal plan
    - Click on meal plan to see details.
- Toggle view
    - Click on Day, Week, Month.
    - Follow View meal plan
